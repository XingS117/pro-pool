## 第三部分：微信小游戏工程现状（已完成）

目录 wechat-minigame/：
- adapter.js：把浏览器 API 映射到 wx API（Canvas、WebAudio、atob、本地存储、DOM 桩、rAF）
- core.js：核心 bundle，由 node scripts/build-minigame.mjs 从网页版 js/ 自动生成（config/physics/renderer/audio/ai/levels/game 共 445KB，不含 DOM 主程序）
- mg-main.js：Canvas UI（主菜单 / 对局 / 击球点面板 / 结算）、触控输入、力度条、分享卡片、首屏隐私弹窗
- game.json、project.config.json（compileType=game，appid 需替换）
- README.md：导入与发布说明

**v1 范围（刻意收敛，降低首审变量）**：单人挑战（三档 AI）、双人对战、拖动瞄准 + 虚影母球、力度条与出杆、11 击球点、自由球拖动、犯规与胜负判定、首屏隐私弹窗、分享卡片。**暂不含**关卡、商店与广告。

**回归保障**：核心 bundle 已在 Node 无头环境冒烟通过（加载、出杆、球体状态正常）；网页版 30 套测试全绿；小游戏侧改动后需再跑 node scripts/build-minigame.mjs 重新生成 core.js。
