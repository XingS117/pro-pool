# 适龄提示设置指引

**适用软件**：一杆入袋台球游戏软件　**版本**：V1.0

## 建议适龄：8 周岁以上

## 判断依据

| 维度 | 说明 | 结论 |
|---|---|---|
| 内容表现 | 无人物形象、无暴力、无血腥、无恐怖元素 | 安全 |
| 语言文字 | 无脏话、无歧视性表达、无敏感内容 | 安全 |
| 交互操作 | 拖动瞄准、点按击球点、拉拽力度，无文字输入与社交沟通 | 安全 |
| 消费诱导 | 无内购、无广告、无虚拟货币充值、无抽奖 | 安全 |
| 社交关系 | 无好友、无聊天、无陌生人社交、无排行榜炫耀机制 | 安全 |
| 沉迷风险 | 单局时长短、无连续任务、无签到、无体力限制压迫 | 低风险 |
| 知识获取 | 无暴力知识、无危险行为示范 | 安全 |

## 建议后台填写内容（微信小游戏后台「适龄提示」）

- **适龄提示**：8+
- **适龄说明**：本游戏为休闲体育竞技类游戏，画面为球桌与台球，无人物、无暴力、无恐怖、无色情内容，无内购与广告，无需注册登录，无社交聊天功能，不存在诱导消费或沉迷风险。
- **内容安全**：无

## 备选

若审核要求提供更保守档位，可填 12+；依据同上，8+ 属于合理推荐值。
