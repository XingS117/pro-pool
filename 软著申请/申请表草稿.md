## 四、软件用途与技术特点

### 用途
一款运行于浏览器及微信小游戏平台的休闲八球台球游戏，支持人机对弈、双人对战、关卡挑战与球杆收集等玩法，完全离线运行，不含第三方运行时依赖。

### 技术特点
1. **连续碰撞检测**：物理积分采用固定 1/600 秒子步长；通过解算相对运动方程求取精确接触时刻，并以该时刻球心连线作为碰撞法线，使出球方向与界面辅助线所呈现的几何方向严格一致，实测方向误差为 0 度。
2. **分离滑动与滚动摩擦**：击球点位置决定初始角速度，经滑动摩擦转化为滚动状态，实现跟进、回缩等真实走位效果。
3. **真实袋口建模**：库边在袋口处断开并设置袋角反弹；落袋判定综合考虑球心是否越过台呢边界、球速是否仍有冲劲及球心与袋心距离，消除球停在袋口反复抖动等异常。
4. **旋转与库边偏转**：左右塞产生绕铅垂轴旋转，改变碰库反弹角度；旋转随时间指数衰减。
5. **分层人工智能**：候选球路枚举、物理模拟评估、角度与力度微调搜索、出口自检四段式流程；三档难度通过搜索范围、模拟次数与修正窗口区分，高难度档对所有可瞄球要求直接进袋并具备连续清台能力。
6. **程序化美术**：球桌、球体、球杆、界面全部由 Canvas 2D 程序化绘制，球体明暗、号码贴图与滚动姿态实时投影，不加载任何外部图片资源。
7. **零依赖单文件交付**：全部样式与脚本内联于单个 HTML 文件，运行时无网络请求，可直接本地打开，亦可部署于任意静态托管。
8. **完整八球规则**：开球开放球台、两球吃库、自由球、球组判定与黑八胜负条件均已实现。
