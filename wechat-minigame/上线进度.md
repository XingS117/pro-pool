## 二、待办（需要你操作，我配合）

### 1. 补充服务类目（最优先，后面都依赖它）

- 位置：后台首页 →「小程序类目 → 补充」，或直接开 <https://mp.weixin.qq.com/wxamp/category/get?simple=1&lang=zh_CN>
- 点「添加类目」→ **需要用管理员微信扫码验证**（这一步是微信强制要求，我无法代扫）
- 选择：
  - 一级类目：**游戏**（注册时已固定，不可改）
  - 二级类目：**休闲**（台球属休闲体育竞技）
  - ⚠️ 个人主体**不能选**「角色类」「牌类」「文化互动」
- 提交后类目即时生效

### 2. 配置隐私保护指引

- 位置：后台 → 设置 → 服务内容声明 → 用户隐私保护指引
- 隐私协议链接填：`https://xingshuwen.com/games/pool/privacy.html`
- 声明的信息类型：**不收集任何个人信息**（无账号、无位置、无通讯录）

### 3. 设置适龄提示

- 位置：后台 → 设置 → 适龄提示
- 选 **8+**，说明文案见 `软著申请/适龄提示.md`

### 4. 上传代码

- 打开微信开发者工具（已装好：`C:\Program Files (x86)\Tencent\微信web开发者工具`）
- 「导入项目」→ 目录选 `wechat-minigame/`（或解压 `dist/pro-pool-wechat-minigame.zip`）→ 项目类型选**小游戏**
- AppID 已填好；若提示不属于当前账号，用管理员微信扫码登录工具
- 点「编译」→ 模拟器能玩 → 点「上传」→ 版本号填 `1.0.0` → 扫码确认

### 5. 提审 → 发布

- 后台 → 版本管理 → 开发版本 → 提交审核（附软著证书、自审报告、隐私链接）
- 审核通过后点「发布」

### 6. 小程序备案（可与开发并行）

- 位置：后台 → 设置 → 基本设置 → 小程序备案
- ⚠️ 需先完成类目补充，且需你的**身份证信息**实名

### 7. 微信认证（影响能否被搜到，建议做）

- 后台 → 设置 → 基本设置 → 微信认证
- 后台原文：**「完成微信认证后，账号可获得"被搜索"和"被分享"能力。未完成微信认证不影响后续版本发布」**
- 即：**不认证 → 别人在微信里搜不到、也分享不了**。这对"让更多人玩"是硬性阻碍
- 个人主体认证费用以后台显示为准（通常几十元/次）

## 三、怎么在微信里查到这个游戏

### 现在查不到，原因有三个

1. **代码还没上传**（版本管理里没有版本）
2. **还没提审发布**（未上线）
3. **没做微信认证**（无"被搜索"能力）

### 发布之后，三种进入方式

| 方式 | 怎么做 | 前提 |
|---|---|---|
| 微信搜一搜 | 微信顶部搜索框输入「**一杆入袋**」 | 已发布 + **已认证** |
| 小程序码 | 后台 → 设置 → 基本设置 → 小程序码 → 下载/保存，扫码即进 | 已发布 |
| 分享卡片 | 游戏内右上角菜单 → 转发给好友/群 | 已发布 + 已认证（否则"被分享"能力受限） |

### 想立刻验证能不能玩（不用等发布）

- 开发者工具点「预览」→ 生成二维码 → 手机微信扫码，**立刻就能在手机上玩**（这是体验版，不需要审核）
- 或点「上传」后，在后台设成「体验版」，把体验版二维码发给 1-2 个朋友试玩
