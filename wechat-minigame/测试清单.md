## 一、首页（启动即可玩，无任何阻断页）
- [ ] 标题「一杆入袋 / PRO POOL」，下方一支真实质感球杆（当前装备的那支）
- [ ] 顶部显示金币数、星星数；下方显示「通关 x/12 · 胜 x 负 x」和三颗真实台球装饰
- [ ] 六个功能按钮：单人挑战 / 双人对战 / 闯关练习 / 球杆商店 / 设置 / 玩法说明

## 二、对局（点「单人挑战」或「双人对战」）
- [ ] 顶部对战条：**真实台球**（带号码和花色腰带），按全色 1-7 / 花色 9-15 排列；进一颗球对应号码变成空槽
- [ ] 顶部 VS 与「你的回合 / AI 回合」提示；对战条与球台等宽，不遮挡右上角微信胶囊
- [ ] 右侧控制栏（上→下）：菜单☰ / 击球点 / 力度条 / 音乐♪ / 辅助线
- [ ] **力度条**：从上往下覆盖，**往下拉力度增大，松手自动出杆**，拖动时力度数字放大
- [ ] 底部角度标尺：带边框，左右拖动微调角度
- [ ] 击球点：点右侧白球图标进 11 预设页，4+4+3 工整排列，末行居中
- [ ] 音乐♪ / 辅助线 开关可点，状态即时变化
- [ ] **切换回合有音效**（这次补上的）
- [ ] 击球/落袋/碰库/赢/输音效都有（引擎自带）

## 三、暂停（点右侧菜单☰）
- [ ] 弹出「已暂停」，三个按钮：继续游戏 / 重新开始本局 / 退出到主菜单
- [ ] 继续游戏后球局状态保持，不丢失

## 四、闯关练习（首页入口）
- [ ] 12 关网格，每关显示编号、名称、星星（0-3 颗）
- [ ] 第 2 关起需通过上一关才解锁
- [ ] 点关卡进入，目标是打进指定球；胜负后结算金币

## 五、球杆商店（首页入口）
- [ ] 9 支球杆列表，**每支都画了真实质感的球杆**（木纹渐变、接环、握把纹理、皮头）
- [ ] 显示球杆名称、定位（力量/旋转/辅助线侧重）、数值、解锁条件
- [ ] 已拥有→点击装备；未拥有→金币/星星够则购买并装备，不够则提示差多少
- [ ] 不同球杆性能有差异（力量、旋转、辅助线长度）

## 六、设置（首页入口）
- [ ] 音效开关 / 辅助线开关 / 白天黑夜模式 / 背景音乐开关，四行都可点，状态即时显示

## 七、玩法说明（首页入口）
